# Listen to the town

Веб-синтезатор на Tone.js. Арт-практика, ДиП ВШЭ, 2 курс, модуль 1.

Ночной город, который можно слушать и играть на нём. Окна в домах работают как секвенсор: по ним слева направо идёт невидимая каретка, и каждое горящее окно звучит, когда до него доходит очередь. Чем выше окно на экране, тем выше нота.

## Как играть

Открыть `index.html` в браузере. На старте всё стоит на паузе, звук и механики включаются тогглом.

| Объект | Действие | Что происходит |
| --- | --- | --- |
| Небо | click | из точки клика падает капля и звучит, когда касается крыши |
| Окна | click | окно загорается или гаснет, нота добавляется в мелодию или пропадает |
| Луна | drag ↕ | громкость гула: выше луна, громче гул |
| Туман | drag ↕ | больше эха, звук глохнет |
| День / вечер / ночь | click | другой лад, темп, тембр окон, ритм и стартовый рисунок окон |

## Устройство звука

```
окна     PolySynth (FMSynth) → Chorus → FeedbackDelay → Filter → Reverb → Channel
капли    Synth → FeedbackDelay → Reverb → Channel
луна     PolySynth (fattriangle) → Filter → Reverb → Channel
город    Noise → AutoFilter → Channel
ритм     MembraneSynth → Filter → Channel
```

16 колонок окон дают 16 шагов по восьмой, это 2 такта. Нота окна берётся из лада режима по высоте окна на экране.

|  | день | вечер | ночь |
| --- | --- | --- | --- |
| Лад | до мажор | ре дорийский | ля минор |
| Темп | 100 | 76 | 56 |
| Окна | короткий звонкий звук, почти без эха | мягкий звук с хорусом и дилеем | стеклянный колокольчик, длинный реверб |
| Город | громкий | тише | почти тишина |
| Ритм | бочка на каждую долю | редкая бочка | сердцебиение |
